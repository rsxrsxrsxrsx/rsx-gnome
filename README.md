# rsx — твики GNOME Shell

Личное расширение для GNOME Shell 50 (Ubuntu). Всё включается и выключается
в настройках расширения.

**Рабочий стол**
- Подписи окон в обзоре (Super): иконка и название под каждым окном.
- Окна одного размера в обзоре, ровные ряды.
- Пружинная анимация открытия и закрытия обзора.
- Полупрозрачная верхняя панель с размытыми обоями.
- Alt+Tab как в macOS: крупные иконки приложений в ряд.
- Скруглённые углы экрана.
- Новые окна открываются по центру, с пружинной анимацией открытия и закрытия.
- Индикатор громкости и яркости в стиле macOS, снизу по центру.
- Динамический остров: музыка и уведомления в чёрной пилюле сверху.
- Потряси мышкой, и курсор станет большим.
- Человечек на рабочем столе: бегает, машет рукой, залезает на окна, танцует под музыку,
  засыпает, когда тебя нет, бежит к уведомлениям, напоминает попить воды и лечь спать. Его можно
  таскать мышкой, бросать, щекотать, гладить и бить быстрыми кликами (правый клик — прыжок).
  Позы лежат в `sprites/`, звуки можно положить в `sprites/sounds/` (`hit*`, `fall*`, `laugh*`).
- История буфера обмена по Super+V: поиск, текст и картинки, вставка по Enter.
- Сочетания с Ctrl (Ctrl+V, Ctrl+Shift+V и т.д.) работают в любой раскладке во всех
  программах, включая JetBrains, Electron и терминалы.

**Блокировка и вход**
- Экран блокировки в стиле macOS: часы сверху, аватар и поле пароля снизу.
- Английская раскладка на экране блокировки.
- Обложка играющего трека с кнопками и приветствие по времени суток.
- Цветной дым за мышкой на экранах блокировки и входа (симуляция жидкости на видеокарте).
- Экран входа (GDM) в том же стиле.

Интерфейс на русском или английском, по языку системы.

## Установка на новом компьютере

```bash
git clone https://github.com/rsxrsxrsxrsx/rsx-gnome.git ~/.local/share/gnome-shell/extensions/rsx@rsx
```

Выйти из сессии и войти снова (на Wayland GNOME видит новые расширения только
после перезахода), затем:

```bash
gnome-extensions enable rsx@rsx
```

Настройки: приложение «Расширения» → rsx, или `gnome-extensions prefs rsx@rsx`.

### Экран входа (по желанию)

```bash
sudo ~/.local/share/gnome-shell/extensions/rsx@rsx/install-gdm.sh
```

Копирует расширение в систему, включает его для экрана входа и переносит
раскладку мониторов. Запускать заново после обновлений. Убрать:
`sudo ~/.local/share/gnome-shell/extensions/rsx@rsx/install-gdm.sh --uninstall`.

## Обновление

```bash
cd ~/.local/share/gnome-shell/extensions/rsx@rsx && git pull
```

И перезайти в сессию.

## Разработка

`./dev.sh` запускает вложенный GNOME Shell в окне с тестовыми программами,
чтобы проверять изменения без перезахода.
